Product types

Three builds, three failure personalities

The AI4I machine ships as three quality variants. They are not just cosmetic — the overstrain limit, the duty cycle and the failure mix all differ, which is why Type is shown to the diagnosis rules even though the model itself found little use for it.

Model performance

99% accuracy — and the number that matters more

Failures are only 3.4% of the data, so a model that never predicts one still scores ~97%. Getting to 99% is mostly the easy majority class — the metrics we actually hold it to are recall (real failures caught, 84%) and precision (alerts that were right, 78%), reported on a validation set watched during development and a test set scored once at the end.

Confusion matrix — 2,000 held-out readings, 68 real failures
The 60 / 20 / 20 split

Of 10,000 readings: 6,000 train the model, 2,000 validate it while it is built, 2,000 are sealed until the final score. The failure rate (~3.4%) is held constant across all three by stratified sampling.
